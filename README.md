Developed a Udemy Clone website using HTML and CSS, inspired by the design and layout of the Udemy online learning platform. The website provides a clean and user-friendly interface for displaying online courses and learning content.

The project includes a navigation bar, search section, course categories, promotional banner, popular courses, course cards, instructor information, pricing details, ratings, and footer section. CSS was used to create attractive layouts, spacing, typography, borders, and hover effects.

The website was designed using Flexbox to arrange course cards and other elements efficiently. I also focused on maintaining a structured, responsive, and visually appealing layout similar to a real-world educational platform.

Technologies Used: HTML5, CSS3, Flexbox

Key Features:

Udemy-inspired navigation bar
Course search interface
Course categories
Popular and recommended courses
Course cards with images, titles, ratings, and prices
Promotional sections
Instructor/course information
Responsive and organized page layout
Clean UI using HTML and CSS
